# Day28 学习记录：通信稳定性优化

## 今日目标

将 Day27 跑通的完整链路进行稳定性优化，让项目从“能跑”变成“更像工程项目”。

## 今日完成内容

1. Linux Gateway 增加日志时间戳
2. 增加 MQTT 断线自动重连配置
3. JSON 解析支持 "cmd": "OPEN" 这种带空格格式
4. 增加命令去重机制
5. STOP 急停命令不参与去重
6. 串口发送增加失败重试机制
7. 无效命令 HAND_NONE 不发送给 STM32
8. 无 cmd 字段的 JSON 直接丢弃

## 优化后的链路

ESP32-S3
        ↓ MQTT
Linux Gateway
        ↓ JSON 解析
        ↓ 命令去重 / STOP 优先级 / 日志记录
        ↓ UART 重试发送
STM32F407
        ↓ I2C
PCA9685
        ↓ PWM
MG90S

## 今日收获

今天重点不是新增功能，而是工程稳定性：
- 通信链路要能排错
- 错误消息不能影响执行端
- STOP 要具备最高优先级
- 串口发送失败要有重试
- 重复命令要限流
